# Sketch Explainer Studio

A single-page tool for making vertical "in 90 seconds" explainer videos in a pencil-sketch style: a title card, captioned scenes with slow zoom and pan, and an optional voiceover.

Open `index.html` in a browser (Chrome, Edge or Safari).

1. Write your script and split it into 5–10 points, one per scene.
2. Use **Copy prompt** on each scene to get an image prompt, and generate the illustration in your image tool.
3. Upload the images, edit the captions (wrap words in `*asterisks*` to highlight them) and the title card.
4. Add a voiceover if you have one. Scenes stretch to its length.
5. Press **Record video**, keep the tab open until it finishes, then save the MP4. **Save cover PNG** exports the title card.
